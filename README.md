# Лабораторная работа №2 - jQuery Портфолио

## Описание

Сайт-визитка с динамическим поведением на jQuery. Реализованы все требования лабораторной работы.

## Что сделано

- Выпадающее меню для мобильных
- Форма обратной связи с валидацией
- AJAX отправка формы
- Модальное окно
- Динамическая галерея портфолио из JSON
- Карусель навыков с автопрокруткой
- Анимации и эффекты
- Подсветка активного меню при скролле
- Кнопка "Вверх"

## Технологии

- HTML5, CSS3, JavaScript
- jQuery 3.6.0
- Font Awesome иконки
- JSON для данных портфолио

## Запуск

1. Запустите локальный сервер:
```bash
python -m http.server 8000
```

2. Откройте http://localhost:8000 в браузере

## jQuery функции

- `$(document).ready()` - инициализация
- `$.getJSON()` - загрузка портфолио
- `$.ajax()` - отправка формы
- `fadeIn()`, `fadeOut()` - анимации
- `animate()` - плавная прокрутка
- `on()` - обработчики событий
- `addClass()`, `removeClass()` - управление CSS
