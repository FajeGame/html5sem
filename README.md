# Лабораторная работа 3 - Рефакторинг портфолио на SCSS/Sass

Сайт-визитка портфолио с рефакторингом на SCSS.

## Структура
```
scss/
├─ base/        # reset, typography
├─ components/  # кнопки, карточки
├─ layout/      # header, footer
├─ themes/      # светлая/тёмная тема
├─ utils/       # переменные, миксины
└─ main.scss   # точка входа
```

## Этапы
1. Базовая структура +
2. Переменные и миксины +
3. Компоненты и темы
