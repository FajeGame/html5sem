# To-Do List с TailwindCSS

Веб-приложение для управления задачами на HTML5, JavaScript и TailwindCSS.

## Функциональность

- **Добавление/редактирование/удаление задач** через модальное окно
- **Переключение статуса** выполнения задач
- **Поиск задач** в реальном времени
- **Переключение тем** (светлая/темная) с сохранением
- **Автоматическая сортировка** на активные и выполненные
- **Сохранение в LocalStorage**

## Технологии

- HTML5, TailwindCSS, Vanilla JavaScript, SCSS
- Адаптивный дизайн для всех устройств
- Dark mode через классы TailwindCSS или SCSS

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python -m http.server 8000
```

## Использование

1. **Добавить задачу**: кнопка "Добавить задачу"
2. **Редактировать**: иконка карандаша
3. **Удалить**: иконка корзины
4. **Выполнить**: галочка рядом с задачей
5. **Поиск**: поле ввода вверху
6. **Тема**: кнопка луны/солнца
