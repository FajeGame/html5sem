# To-Do List

Приложение для управления списком задач с поддержкой светлой и тёмной темы.

## Функциональность

✅ **Управление задачами:**
- Добавление новых задач через модальное окно
- Редактирование существующих задач
- Удаление задач
- Отметка задач как выполненных

✅ **Поиск:**
- Динамический поиск задач по названию

✅ **Темы:**
- Переключение между светлой и тёмной темой
- Сохранение выбранной темы в localStorage

✅ **Адаптивность:**
- Полностью адаптивный дизайн для мобильных устройств и десктопов

✅ **Хранение данных:**
- Все задачи сохраняются в localStorage браузера

## Структура проекта

```
lab4/
├── index.html          # Основная HTML разметка
├── js/
│   └── main.js         # JavaScript логика приложения
├── styles/
│   ├── main.scss       # Главный SCSS файл
│   ├── main.css        # Скомпилированный CSS
│   ├── _variables.scss # Переменные (цвета, отступы, радиусы)
│   ├── _mixins.scss    # Миксины для переиспользования кода
│   ├── _base.scss      # Базовые стили
│   ├── _header.scss    # Стили для заголовка
│   ├── _controls.scss  # Стили для элементов управления
│   ├── _todos.scss     # Стили для списка задач
│   └── _modal.scss     # Стили для модального окна
└── README.md           # Документация
```

## Технологии

- **HTML5** - семантическая разметка
- **SCSS/SASS** - препроцессор CSS с модульной структурой
- **Vanilla JavaScript** - чистый JavaScript без фреймворков

## Запуск проекта

1. Откройте файл `index.html` в браузере
2. Для компиляции SCSS в CSS используйте команду:
   ```bash
   npx sass styles/main.scss styles/main.css
   ```

## Использование

1. **Добавление задачи:** Нажмите кнопку "+ Добавить задачу"
2. **Редактирование:** Нажмите на иконку ✏️ рядом с задачей
3. **Удаление:** Нажмите на иконку 🗑️ рядом с задачей
4. **Отметка выполнения:** Установите галочку в чекбоксе задачи
5. **Поиск:** Введите текст в поле поиска
6. **Смена темы:** Нажмите на кнопку с луной/солнцем в правом верхнем углу

## Особенности реализации

- Семантическая HTML разметка с использованием `<section>`, `<header>`, `<button>` и других тегов
- Модульная структура SCSS с использованием partials
- Организация стилей через переменные и миксины
- Использование CSS Grid и Flexbox для адаптивной верстки
- Поддержка медиа-запросов для мобильных устройств
- Работа с localStorage для сохранения данных
- Динамическое обновление DOM
- Анимации и переходы для улучшения UX
